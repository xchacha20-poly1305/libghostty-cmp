Ghostty Web Terminal — Kotlin/js

Unzip the complete folder, then open index.html in your browser.
No server or installation is needed. The terminal itself runs without a network connection.
CJK and emoji fonts download from Google Fonts and jsDelivr when the browser is online.
The Kotlin/JS application uses WebAssembly for Ghostty and Skiko.
WebGL 2 is required.
This is a simulated shell with an in-memory filesystem. Refresh to reset it.
Clipboard API availability depends on browser permissions; ordinary browser paste events are supported.
