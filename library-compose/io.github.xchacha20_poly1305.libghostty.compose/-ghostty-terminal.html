GhosttyTerminal

@Composable
fun GhosttyTerminal(session: GhosttyTerminalSession?, modifier: Modifier = Modifier, state: GhosttyTerminalState = rememberGhosttyTerminalState(), theme: GhosttyTheme? = null, darkColorScheme: Boolean = isSystemInDarkTheme(), fontFamily: FontFamily = FontFamily.Monospace, fontSize: TextUnit = 14.sp, focusOnAttach: Boolean = true, contentPadding: PaddingValues = PaddingValues(0.dp), contentPaddingMode: GhosttyContentPaddingMode = GhosttyContentPaddingMode.SCROLL_UNDER, onFontSizeChanged: (TextUnit) -> Unit = {}, onFinishedSessionKey: () -> Unit = {})

Shows session and sends it what the user types. Pair it with GhosttyDialogs for the prompts the terminal raises. Widgets sharing the same state add the rest, and an app may use its own instead: GhosttyExtraKeysBar below it, GhosttyScrollIndicator and GhosttyJumpToBottomButton over it.

Parameters

fontSize

applies whenever it changes; pinch zoom moves away from it and reports through onFontSizeChanged.

contentPadding

keeps rows clear of whatever covers the edges of the view, as contentPaddingMode describes. Horizontal padding narrows the grid in either mode.
