interface GhosttyStickyModifiers

Modifiers held outside the keyboard, such as the Ctrl and Alt of an extra keys bar. Set on GhosttyTerminalState.stickyModifiers, they apply to the next key the terminal sends, whether it comes from a keyboard, the input method or GhosttyTerminalState.sendKey.

State and settings of a GhosttyTerminal. Widgets around the terminal, such as GhosttyExtraKeysBar, GhosttyJumpToBottomButton, GhosttyScrollIndicator and GhosttyDialogs, work through this state only, so an app can replace any of them with its own.

ghosttyExtraKey

fun Modifier.ghosttyExtraKey(state: GhosttyTerminalState, repeatable: Boolean = false, interactionSource: MutableInteractionSource? = null, onPress: () -> Unit): Modifier

Handles presses on a key button outside the terminal, such as one of an extra keys bar: fires onPress on release, and when repeatable is set, repeatedly while held instead. A touch that a scrollable parent takes over as a drag fires nothing, so the keys can sit in a scrolling row. Every gesture restores the terminal input and software keyboard of state so the button does not take the input target away from it. The gesture consumes the release, so the button must not also be clickable; pass an interactionSource to drive Modifier.indication from it instead.
