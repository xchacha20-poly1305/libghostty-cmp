GhosttyTerminalState

@Stable
class GhosttyTerminalState

State and settings of a GhosttyTerminal. Widgets around the terminal, such as GhosttyExtraKeysBar, GhosttyJumpToBottomButton, GhosttyScrollIndicator and GhosttyDialogs, work through this state only, so an app can replace any of them with its own.
