fun install(terminfoDir: File)

Writes the compiled terminfo entry to terminfoDir/x/xterm-ghostty. The host points TERMINFO (or the terminfo search path of its libc) at terminfoDir, sets TERM=xterm-ghostty, and passes TERM as io.github.xchacha20_poly1305.libghostty.GhosttyTerminalSession.Options.terminfoName.
