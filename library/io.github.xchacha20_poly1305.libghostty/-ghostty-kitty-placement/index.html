GhosttyKittyPlacement

data class GhosttyKittyPlacement(val imageId: Int, val imageGeneration: Long, val column: Int, val row: Int, val offsetX: Int, val offsetY: Int, val width: Int, val height: Int, val sourceX: Int, val sourceY: Int, val sourceWidth: Int, val sourceHeight: Int, val z: Int, val layer: GhosttyImageLayer = when { z < Int.MIN_VALUE / 2 -> GhosttyImageLayer.BELOW_BACKGROUND z < 0 -> GhosttyImageLayer.BELOW_TEXT else -> GhosttyImageLayer.ABOVE_TEXT })

Where to draw part of a Kitty graphics image: the source rectangle of the image, in pixels, onto a width x height pixel rectangle that starts offsetX, offsetY pixels into the viewport cell at column, row. The row is negative when the image starts above the viewport. Draw in layer order, then by z.
