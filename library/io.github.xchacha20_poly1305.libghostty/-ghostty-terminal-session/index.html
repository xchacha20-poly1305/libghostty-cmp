GhosttyTerminalSession

class GhosttyTerminalSession(options: GhosttyTerminalSession.Options = Options())

Threading: feedOutput and finish may be called from any thread. All other methods and property writes must happen on the main thread. State flows, EventListener and GhosttyTerminalHost methods are called on the main thread, except exitStatus, which is updated on the thread that calls finish. Transport methods may be called from any thread that calls feedOutput, and from the main thread; implementations must be thread safe and must not block.

Lifecycle: close is idempotent; after it, every method is a no-op.
