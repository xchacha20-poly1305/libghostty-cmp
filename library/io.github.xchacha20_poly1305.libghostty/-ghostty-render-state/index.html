GhosttyRenderState

class GhosttyRenderState

What a renderer draws: the viewport grid, cursor and images of a terminal. update applies the rows the terminal changed since the last update, so the state is meant to live as long as the renderer.

Cell colors are final ARGB values: defaults, inverse video and the selection are already applied.
